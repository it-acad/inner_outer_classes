# Sprint3: Inner, outer class. Enum
## Task 4 Implementing an Enum for Line Types

Create an enum named LineType that represents different types of lines, with the following constants: **SOLID**, **DOTTED**, **DASHED** and **DOUBLE**.

Write a method that accepts a value of the **LineType** enum as an **argument**. 
The method should return a formatted string in the following structure:
```
The line is <LineType> type
```
Replace <LineType> with the name of the enum constant converted to **lowercase**.
For example, if the input is LineType.DOTTED, the method should return:
```
The line is dotted type
```
> **For correct test execution, avoid using System.out.print or System.out.println in your code.**
